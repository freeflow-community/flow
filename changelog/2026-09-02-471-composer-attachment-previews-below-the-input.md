# Composer attachment previews below the input (#471)

- `[web]` `[macos]` `[ios]` Pending attachment thumbnails now render below the
  composer's input row instead of above it, so the composer reads
  top-to-bottom: what you typed, then what you attached.
- `[web]` The strip also moved inside the composer's border (it used to sit
  outside, above the card). Remove (✕), multi-attach, drag/paste/picker and
  scheduled send are unchanged.

## Feature

- **Attachments now show under what you're typing.** Attach or paste an image
  and its thumbnail appears below the message box, inside the composer, rather
  than pushing your text down from above.
