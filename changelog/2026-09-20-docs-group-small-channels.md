# Sidebar: a channel with a few docs lists them plainly

- `[web]` The Docs header (caret, label, count, filter) under a channel now
  appears only from four docs up. One to three docs are plain rows under the
  channel, as the macOS client draws them; the fold and filter stay for the
  long lists #574 built them for.

## Feature

- **Less clutter under channels with a doc or two.** A channel's docs sit
  right under its name again; the collapsible "Docs" header with a filter
  appears only when a channel has four or more.
