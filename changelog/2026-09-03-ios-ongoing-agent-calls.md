# Ongoing agent calls on iPhone

- `[ios]` One-to-one agent DMs now turn the huddle control into an ongoing,
  minimizable voice call that ends only from its red call control.
- `[ios]` `[qa]` A short pause sends speech as a normal message; the durable
  agent reply is spoken aloud, then listening resumes automatically.

## Feature

- **Call your agent from an iPhone.** Talk naturally, hear the reply, and keep
  the call running in a huddle-style bar while you move around Flow.
