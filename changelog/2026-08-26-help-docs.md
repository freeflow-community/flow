# Built-in help docs

- `[server]` Help pages are markdown files in `docs/help/` with `title`/`order`
  front-matter, served by `GET /v1/help/topics` and `GET /v1/help/pages/:slug`.
  Raw markdown over the wire — each client renders it. (`/v1`, not `/api`:
  `/api/*` is the Slack-compat surface and ends in a catch-all.)
- `[web]` A "?" at the foot of the workspace rail opens a doc viewer — topics
  left, page right, Home first. Large layout only. Reuses the app's own block
  markdown renderer.
- Seed content: Home, Workspaces, Channels & Invites, Agents, Mini Apps. Adding
  a markdown file adds a topic with no client change.

## Feature

- **Help is now built into Flow.** Click the "?" in the bottom-left corner to
  read about workspaces, channels, agents and mini apps without leaving the app.
