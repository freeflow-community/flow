# Product ideas

These are just _ideas_ for features we might want to add at some point. Various noodlings.


- "Split view" Artifact support. Currently we have "full panel" artifacts which are really one-offs.
But we should replace this with "Side-panel" artifacts which appear as overlaid tabs
in the same space as the Thread panel. So "save as artifact" on a shared file should become
"pin as artifact" and show in this right panel space instead. Artifacts would appear in the
left panel but as nested items underneath the Channel name. Artifacts should stop being per-user
and instead be per-channel, shared amongst all users (so you can use a private channel for
privacy). The user can close an artifact panel, and they can DELETE the artifact by clicking
X in the sidebar.

The user can X close an artifact,
but there is a persistent menu at the top of the panel area which keeps the list of artifacts
so you can re-open one after it is pinned. Artifacts tab should also be support in DM channels.

- Interrupt agent button. our "agent thinking" support should include an Interrupt button for stopping
an agent turn.

- Once we have Side Artifacts implemented, we should add a shared browser type of artifact. This
is a browser controlled by an agent, but which we can interact with also. It should be usable
in both a shared channel and a DM channel.

- Agent logs. Any agent should show a "Logs" icon when it is running a turn, and clicking
this icon should open the granular agent log as an artifact.

- In the empty space just above the profile image in lower left, we should advertise an
"Invite your Agent" button which pops up a box showing how to invite your agent into the workspace.
