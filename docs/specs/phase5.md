# Phase 5 - additional features

1. in chat, file attachments should show a "Download" icon on hover to download the attachment
2. Add support to render animated gifs
3. Images in chat should have a "hide/show" arrow icon that collapses/opens the image when clicked. Shared images are open by default.
4. Shared files should show small preview in the prompt area
5. Clicking a shared image should show it expanded in a popup modal inside the app itself. "Open external" should be via an icon button
6. Width of thread display panel should be adjustable
7. In main chat, the "<N> replies" label should also show the avatars of the first 4 people in the replies thread
