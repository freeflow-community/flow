# Phase 6 - file previews

We have good support for images and image previews, but we need to add more support:

- text file preview in chat. Shows a text file with a monospace font, limited length with an "expand" button
to show the whole thing. Should work for any ASCII format files like markdown, code files, .txt files, etc...

- PDF file preview. Shared PDFs should render a mid-size preview, and support clicking to open a full reader.
