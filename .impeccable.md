## Design Context

### Users

Software teams — developers, PMs, and their AI coding agents — living in Flow
all day as their primary communication surface, the way teams live in Slack.
Two audiences share every channel: humans reading/writing prose, and agents
posting structured updates, artifacts, and code. Users are technical, keyboard-
fluent, and switching constantly between Flow, an editor, and a terminal. The
job: coordinate work (with humans *and* agents) without the tool ever getting
in the way. Flow is open-source and self-hostable; its pitch is "commercial-
competitive, corporate-free" — the design must feel *better* than the
commercial incumbents, not like a budget clone of them.

### Brand Personality

**Precise, warm, quietly confident.** "What would this feel like if Apple made
a team chat app" — restrained, physics-real, impeccable in the details — with
deliberate moments of warmth and whimsy at emotional beats (sending a message,
reactions, empty states, an agent coming online). Premium first, playful
second. The owner is coming off "buzz," which felt smooth and whimsical; the
current Flow UI reads stiff and corporate. Emotions to evoke: calm confidence,
craftsmanship, and small sparks of delight — never noise, never toy-like.

### Aesthetic Direction

- **Theme:** light mode only for now, but ALL color must flow through tokens
  structured so a dark theme is a token swap later, not a rewrite.
- **Color:** full palette freedom — the current Slack-adjacent violet is NOT
  sacred and may be replaced wholesale if it serves the premium goal. Tint
  neutrals toward whatever brand hue is chosen; OKLCH throughout.
- **Constraint:** workspaces have admin-set sidebar color themes
  (`sidebarColor()` presets in `@flow/shared`, picker in
  `WorkspaceColorModal`). Any new palette must either restyle those presets or
  deliberately replace that feature — don't silently break it.
- **Motion:** the current UI has essentially none. Motion is a core part of
  the premium mandate: real easing (ease-out-quart/quint), transform/opacity
  only, `prefers-reduced-motion` respected. Whimsy is concentrated at a few
  beats, not sprayed everywhere.
- **Typography:** currently unstyled system-default sans. A deliberate type
  choice (distinctive but readable at chat densities, 13–15px body) is in
  scope. Chat is a reading surface — density and legibility beat display
  flourish in the message list.
- **Anti-references:** Slack's visual identity (the current UI is a near-clone
  — purple rail, white sheet, flat everything); generic AI-dashboard
  aesthetics; Electron-app heaviness. Flow's macOS app brags "no Electron" —
  the web app should feel native-grade too.

### Design Principles

1. **Chat density is sacred.** This is an all-day reading tool. Hierarchy,
   spacing, and type serve fast scanning of many messages; premium ≠ airy
   marketing-page spacing in the message list.
2. **Motion conveys state, then delights.** Every animation maps to a state
   change (send, arrive, open, dismiss). A handful of signature moments carry
   the personality; everything else is fast and physical (150–250ms, real
   easing, optimistic UI).
3. **Humans and agents are both first-class.** Agent presence, activity, and
   authorship deserve designed treatment — not a robot emoji bolted onto
   human-shaped UI.
4. **Tokens or it didn't happen.** Every color, space, radius, shadow, and
   duration goes through the `@theme` token layer in
   `packages/web/src/index.css`. No inline hex, no one-off magic numbers.
5. **Details are the product.** Focus rings, scrollbars, selection color,
   empty states, loading states, error states — the unglamorous 20% is where
   "premium" actually lives.

### Decided Direction (2026-08-02, owner-approved)

- **Scope:** full premium-ization — visual layer AND interaction architecture
  (popovers over gratuitous modals, one confirm pattern + undo, Cmd+K
  switcher, global focus system).
- **Brand hue:** deep teal-green. Unclaimed by chat incumbents; neutrals stay
  warm-ivory, tinted toward teal. Violet is retired; `sidebarColor()` presets
  get restyled to the new system, not broken.
- **Signature moment:** agent presence & thinking — a designed AI-teammate
  identity (distinct avatar treatment, living "thinking" state, wake-up
  moment). Send-settle and reactions get polished-but-quieter motion.
- **The "works best in the desktop app" banner is removed.** The web client
  stands on its own; download links live on the auth screen and workspace
  chooser only.

### Tech Constraints

- React 19 + Tailwind CSS v4 (`@theme` tokens) + Vite; no component library.
- Web client only for this effort (`packages/web`); macOS (SwiftUI) and iOS
  follow later using the same design language. Parity divergences must be
  logged in CHANGELOG.md's Parity section per repo convention.
- Keyboard-first users: visible focus states and shortcut affordances matter.
